### 🚀 실행 방법 및 주의사항

#### 🪟 Windows
1. 다운로드한 `.zip` 압축을 해제합니다.
2. 폴더 내 실행 파일(`.exe`)을 실행합니다.
3. Windows SmartScreen 경고가 뜨는 경우 **[추가 정보] -> [실행]**을 클릭합니다.

#### 🍎 macOS
1. 다운로드한 `.zip` 압축을 풀고 `.app` 파일을 `응용 프로그램(/Applications)` 폴더로 이동합니다.
2. **필수 권한 설정 (KeyPet / ComPet 공통)**:
   * 백그라운드 키보드/마우스 입력을 감지하기 위해 권한이 필요합니다.
   * **[시스템 설정] -> [개인정보 보호 및 보안] -> [손쉬운 사용]**에서 앱을 허용해 주세요.
3. **미확인 개발자 보안 경고 해결**:
   * 실행 시 "확인되지 않은 개발자" 경고가 뜨면 앱을 **우클릭 -> [열기]**를 선택하거나 터미널에서 아래 명령어를 실행합니다:
     ```bash
     xattr -cr /Applications/앱이름.app
     ```
