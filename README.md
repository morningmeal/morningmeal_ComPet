## 🇺🇸 English

**morningmeal ComPet** is a desktop application designed to boost productivity.  
It features a **Work Timer** that automatically tracks time based on your active window focus, and an interactive **Typing Pet** that responds to keystrokes and mouse clicks in real time while magnetically docking to your timers.

### ✨ Key Features
- **Work Timer**: Recognizes active windows (titles/processes) and only counts actual focused work time
- **Typing Pet**: Reacts to keyboard and mouse inputs, automatically connecting when dropped onto a timer
- **Skin Editor & Per-Skin Animation Control**: Customize squash depth and toggle bounce animations per skin
- **Multi-Language Support**: 한국어, English, 日本語, 简体中文, 繁體中文

#### 🪟 Windows
1. Extract the downloaded `Compet-V3-Windows.zip`.
2. Run `Compet-V3.exe` inside the extracted folder.
3. If a Windows SmartScreen warning appears, click **[More info] -> [Run anyway]**.

#### 🍎 macOS
1. Extract `Compet-V3-macOS.zip` and move `Compet-V3.app` to your `Applications (/Applications)` folder.
2. **Bypass Security Warning ("Unverified Developer / Cannot Check for Malicious Software")**:
   - **Method 1 (Recommended)**: Instead of double-clicking, hold the `Control` key and click (or right-click) the app, choose **[Open]**, and click **[Open]** again in the prompt.
   - **Method 2 (Terminal)**:
     ```bash
     xattr -cr /Applications/Compet-V3.app
     ```
3. **Required Permissions**:
   - Accessibility permission is required to detect background keyboard and mouse input.
   - Go to **[System Settings] -> [Privacy & Security] -> [Accessibility]** and allow `Compet-V3`.
