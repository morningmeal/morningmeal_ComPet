     ```bash
     xattr -cr /Applications/앱이름.app
     ```
3. **필수 권한 설정 (KeyPet / ComPet 공통)**:

1. Extract the downloaded `.zip` file.

#### 🍎 macOS
1. Extract the `.zip` file and move the `.app` bundle to `/Applications`[cite: 1].
2. **Bypass Security Warning ("Unverified Developer / Malicious Software")**:
   * **Method 1 (Recommended - No Terminal)**: Instead of double-clicking, press and hold the `Control` key and click (or **right-click**) the `.app`, then select **[Open]**[cite: 1]. Click **[Open]** again in the confirmation prompt to permanently allow execution[cite: 1].

     xattr -cr /Applications/AppName.app

3. **Required Permissions (KeyPet / ComPet)**:

   * Go to **[System Settings] -> [Privacy & Security] -> [Accessibility]** and enable the app[cite: 1].
